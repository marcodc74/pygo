Pygo v0.2.0: Pygo's own bytecode VM, the `.pgc` compiled format, Python libraries, and guides for using Pygo with LLMs.

## New

- **Bytecode virtual machine, now the default engine.**
  - Pygo compiles every function to its own stack-machine instruction set.
  - It is 1.2–3.5× faster than the tree-walking interpreter: 3.4× on recursive calls, 3.5× on loops and arithmetic.
  - Both engines give identical output, errors, traces and step counts. The test suite checks this on every program.
  - `--engine tree` selects the interpreter.
- **Compiled `.pgc` files.**
  - `pygo compile -o app.pgc app.pg` checks and compiles a program. `pygo run app.pgc` and `pygo test app.pgc` run it without parsing or checking.
  - The format is versioned, checksummed and deterministic. Invalid files are rejected with `E0910`.
  - `pygo build` now embeds bytecode in self-contained executables.
- **`pygo disasm [--json] [--fn name]`** shows the bytecode, with source positions, variable names and operand notes.
- **Python libraries (`extern python`).**
  - Typed, fallible bindings to any Python module, with opaque handles for Python objects.
  - Calls need the `python` capability (`--allow python`).
  - `pygo extern python MODULE NAME...` drafts the declarations from the real Python signatures.
- **Using Pygo with LLMs** (`docs/LLM.md`, `integrations/`):
  - setup for chat apps (ChatGPT, Claude.ai, Gemini);
  - setup for coding CLIs: Claude Code (with a skill), OpenAI Codex CLI, Gemini CLI, opencode, GitHub Copilot, Cursor, Qwen Code, Aider;
  - sandboxed tools and a ready agent for the Claude, OpenAI, Gemini and local-model APIs.

## Install

Download the binary for your platform and rename it to `pygo` (`pygo.exe` on Windows). On Windows you can also run:
`irm https://raw.githubusercontent.com/marcodc74/pygo/master/install.ps1 | iex`.

Then:

```sh
pygo guide                      # compact language reference for a model context
pygo run --allow net app.pg     # run with the net capability
pygo check --json app.pg        # machine-readable diagnostics
pygo compile -o app.pgc app.pg  # compile to bytecode
```

Verify downloads with `sha256sum -c SHA256SUMS`.
See README.md, docs/SPEC.md and docs/BYTECODE.md for details.
